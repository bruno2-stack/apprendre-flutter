Bienvenue dans mon dépôt consacré à l'apprentissage de **Dart et Flutter**, deux technologies qui me permettront de concevoir des applications modernes, interactives et multiplateformes.

Ce projet retrace mon parcours d'apprentissage, depuis les bases de la programmation jusqu'à la réalisation de mes premières applications.

Mon approche repose sur la pratique, la résolution de problèmes, les exercices progressifs et l'utilisation de Git et GitHub pour suivre l'évolution de mon code.

## 🎯 Objectifs du projet

- Apprendre les fondamentaux du langage Dart.
- Comprendre les variables, les types de données, les opérateurs et les structures de contrôle.
- Maîtriser les fonctions, les collections et les mécanismes de gestion des erreurs.
- Découvrir Flutter et son système de widgets.
- Concevoir des interfaces utilisateur modernes et adaptatives.
- Développer des applications mobiles et explorer les autres plateformes prises en charge par Flutter.
- Apprendre à versionner et à documenter mes projets avec Git et GitHub.
- Constituer progressivement un portfolio de projets informatiques.

## 💻 Exécuter les programmes Dart

Dans GitHub Codespaces, place-toi à la racine du dépôt et vérifie l'installation :

```bash
flutter --version
dart --version
git --version
```

Pour exécuter le premier programme :

```bash
dart run 01_decouverte_dart/bonjour.dart
```

Pour exécuter l'exercice sur les variables et les conditions :

```bash
dart run 01_decouverte_dart/exercices_sur_variables.dart
```

## 🌿 Utilisation de Git et GitHub

Chaque étape importante de mon apprentissage peut être enregistrée dans l'historique Git.

**Vérifier les modifications :**

```bash
git status
```

**Ajouter un nouvel exercice :**

```bash
git add 01_decouverte_dart/
```

**Créer un commit :**

```bash
git commit -m "Ajout de nouveaux exercices Dart"
```

**Publier les modifications sur GitHub :**

```bash
git push origin main
```

Ces commandes me permettent de conserver un historique de mes réalisations et de suivre ma progression.

## 📈 Philosophie d'apprentissage

Je privilégie une méthode progressive fondée sur quatre principes :

1. **Comprendre** les notions avant de chercher à mémoriser le code.
2. **Pratiquer** chaque notion à travers des exercices concrets.
3. **Corriger** les erreurs et comprendre leurs causes.
4. **Construire** des projets de plus en plus complets.

Mon objectif n'est pas simplement d'apprendre la syntaxe de Dart ou de Flutter, mais de développer les compétences nécessaires pour concevoir des solutions informatiques utiles.
